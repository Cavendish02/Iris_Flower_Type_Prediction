# Iris Flower Type Prediction App

Welcome to the **Iris Flower Type Prediction App**! This application predicts the type of iris flower (Iris-setosa, Iris-versicolor, Iris-virginica) based on user-provided sepal and petal dimensions.

## Features
- **Data Input:** Users can enter sepal and petal dimensions to get predictions.
- **Model:** The app uses a Logistic Regression model trained on the Iris dataset.
- **Visualizations:** Interactive plots showing data distributions and relationships.
- **Analysis:** Includes descriptive statistics and a correlation matrix for deeper insights into the dataset.

## How to Use
1. Open the application using the following link:
   [Iris Flower Type Prediction App](https://irisflowertypeprediction-6u8svkwejz8ygxsxbys5iy.streamlit.app/)
2. Enter values for sepal length and petal length in the input fields.
3. Click on **Predict** to view the predicted flower type, along with an image and description.
4. Use checkboxes to explore data analysis, visualizations, and model information.

## Dataset Overview
The Iris dataset contains:
- 150 samples of iris flowers
- 4 features: sepal length, sepal width, petal length, petal width
- 3 target species: Iris-setosa, Iris-versicolor, Iris-virginica

## Model Details
- **Algorithm:** Logistic Regression
- **Accuracy:** ~95% on training data

## Running Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/your-repo/iris-flower-prediction.git
   ```
2. Navigate to the project directory:
   ```bash
   cd iris-flower-prediction
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   streamlit run app.py
   ```
